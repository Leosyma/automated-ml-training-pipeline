# Projeto 2 - MLOps Nível 1 - Automação do Pipeline de Machine Learning

Para o desenvolvimento de um pipeline automatizado de Machine Learning, o projeto pode ser modularizado em diferentes etapas, cada uma responsável por um passo específico do pipeline. Vamos estruturar o projeto de maneira profissional, usando scripts separados para cada fase do processo. As etapas principais incluem:

- Extração de Dados
- Limpeza de Dados
- Pré-processamento
- Treinamento do Modelo
- Avaliação do Modelo
- Deploy do Modelo

Cada parte do projeto será representada por um módulo Python e, por fim, um script principal (projeto2.py) irá orquestrar todo o pipeline. Aqui está uma visão geral dos scripts e diretórios:

pipeline/
│
├── dados/                         # Dados brutos e processados
├── modelos/                       # Modelos treinados
├── pipeline/
│   ├── __init__.py                # Inicializador do módulo pipeline
│   ├── extrai_dados.py        # Extração de dados
│   ├── limpa_dados.py         # Limpeza de dados
│   ├── processa_dados.py      # Pré-processamento
│   ├── treina_modelo.py       # Treinamento do modelo
│   ├── avalia_modelo.py       # Avaliação do modelo
│   └── deploy.py              # Deploy do modelo
│
└── projeto2.py                    # Script principal para execução do pipeline

# Passos para execução do projeto:

# Crie um ambiente virtual:

python -m venv .venv

# Ative o ambiente virtual:

# Windows:
.venv\Scripts\activate

# MacOS/Linux:
source .venv/bin/activate

# Execute as instruções abaixo conforme demonstrado nas aulas:

pip install --upgrade pip

pip install -r requirements.txt

python projeto2.py
